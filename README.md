# Synthetic bolometer
This repository hosts a number of syntehic diagnostics developments of bolometer-type plasma diagnostics. Each syntehtic diagnostic is to have its own top-level directory.

## AUG-AXUV
This directory contains synthetic dignostics for ASDEX-Upgrade AXUV diode arrays, specifically for two arrays in Sector 16, but this can be procedurally expanded for Sector 5 and for other arrays as well.

NOTE: For this synthetic diagnostics to work, there are multiple requirements, details in the readme inside the directory.
